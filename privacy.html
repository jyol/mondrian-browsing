Privacy Policy

Last updated: August 10, 2026

Mondrian Browsing (“the Extension”) is a Chrome extension game that lets you paint blocks on a webpage and optionally submit a score to a global leaderboard. This policy explains what information is collected and how it is used.

Information we collect

  • Display name — the nickname you enter the first time you submit a score. It is stored in Chrome’s local extension storage on your device and sent with leaderboard entries.
  • Game score data — painted block count, total blocks, whether you finished, and a short page label (usually the page title or hostname of the site you played on).
  • Submission time — when the score was recorded on our leaderboard database.

The Extension does not collect email addresses, browsing history beyond the single page label attached to a score, payment information, or precise location.

How the data is used

  • To show your name and score on the in-game and website global leaderboard.
  • To remember your display name so you do not have to re-enter it every game.

We do not sell personal data or use it for advertising.

Where data is stored

  • On your device: display name and HUD position preferences via Chrome storage.
  • On our server: leaderboard entries are stored in a Supabase project (cloud database). Scores are readable by anyone who can load the public leaderboard.

Permissions

  • activeTab / scripting — used only when you click the Extension icon, to run the game on the current tab.
  • storage — used to save your display name and HUD preferences locally.
  • Access to Supabase — used to load and save leaderboard scores.

The Extension does not run on every website in the background. Game code is injected only after you click the toolbar icon.

Children

The Extension is a casual game and is not directed at children under 13. Please do not submit personal information belonging to a child.

隐私政策

最近更新：2026年8月10日

Mondrian Browsing（「本扩展」）是一款 Chrome 浏览器插件游戏：你可以在网页方块上涂色，并选择将成绩提交到全球排行榜。 本政策说明我们收集哪些信息以及如何使用。

我们收集的信息

  • 显示昵称 — 你第一次提交分数时输入的名字。它会保存在本机 Chrome 扩展存储中，并随排行榜成绩一并上传。
  • 游戏成绩数据 — 已涂色方块数、总方块数、是否完成，以及简短页面标签（通常是你游玩页面的标题或域名）。
  • 提交时间 — 成绩写入排行榜数据库的时间。

本扩展不会收集电子邮件、完整浏览历史、支付信息或精确位置。

信息用途

  • 在游戏内与网站全球排行榜上展示你的昵称与成绩。
  • 记住你的昵称，避免每局重新输入。

我们不会出售个人数据，也不会将其用于广告。

存储位置

  • 本机：昵称与 HUD 位置偏好（Chrome storage）。
  • 服务器：排行榜成绩保存在 Supabase 云数据库中。公开排行榜上的成绩可被任何人查看。

权限说明

  • activeTab / scripting — 仅在你点击扩展图标时，用于在当前标签页运行游戏。
  • storage — 用于在本地保存昵称与 HUD 偏好。
  • 访问 Supabase — 用于读取与提交排行榜成绩。

本扩展不会在后台对所有网站持续运行；仅在你点击工具栏图标后注入游戏代码。
