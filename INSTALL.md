# Mondrian Browsing — Install Guide / 安装说明
## 中文

### 你需要准备

- **Google Chrome** 浏览器（或 Edge、Brave、Arc 等 Chromium 内核浏览器）
- **Mondrian Browsing** 文件夹（如果收到的是 `.zip` 压缩包，请先解压）

### 安装步骤（约 2 分钟）

1. **打开 Chrome 扩展程序页面**  
   在地址栏粘贴以下内容，然后按回车：  
   `chrome://extensions`

2. **开启开发者模式**  
   打开页面右上角的 **开发者模式** 开关。

3. **加载扩展**  
   - 点击 **加载已解压的扩展程序**（Load unpacked）  
   - 选择 **Mondrian Browsing** 文件夹（里面要有 `manifest.json` 文件）  
   - 点击 **选择** / **打开**

4. **固定扩展图标（推荐）**  
   - 点击 Chrome 工具栏的 **拼图图标**  
   - 找到 **Mondrian Browsing**  
   - 点击 **图钉**，把图标固定在工具栏

### 怎么玩

1. 打开任意普通网页（例如 Wikipedia、新闻网站、博客）。  
   **注意：** 在 `chrome://` 开头的页面和 Chrome 网上应用店 **无法** 使用。

2. 点击工具栏上的 **Mondrian Browsing** 图标，开始游戏。

3. 出现 **Start painting!** 弹窗后，点击关闭（或等待自动消失）。

4. 在 **60 秒** 内尽可能多地 **点击页面上的方块** 进行上色。

5. 第一次完成游戏时，输入你的 **昵称**，即可加入 **全球排行榜**。

6. 再次点击扩展图标可 **关闭游戏**。

### 小提示

- 区块多的网页（导航栏、卡片、列表多）更适合玩，画出来更好看。
- 分数面板顶部的 **红色条** 可以 **拖动** 位置。
- 游戏结束后可以 **下载 PNG 画作**。

### 常见问题

| 问题 | 解决方法 |
|------|----------|
| 点击图标没反应 | 刷新网页后再点一次图标。 |
| 找不到「加载已解压的扩展程序」 | 先打开右上角的 **开发者模式**。 |
| 排行榜无法加载 | 检查网络，并在 `chrome://extensions` 里 **重新加载** 扩展。 |
| 换了新文件夹 | 到 `chrome://extensions`，对 Mondrian Browsing 点击 **重新加载**。 |

## English

### What you need

- **Google Chrome** (or another Chromium browser like Edge, Brave, Arc)
- The **Mondrian Browsing** folder (unzip it if you received a `.zip` file)

### Install (about 2 minutes)

1. **Open Chrome’s extensions page**  
   Copy and paste this into the address bar, then press Enter:  
   `chrome://extensions`

2. **Turn on Developer mode**  
   Switch **Developer mode** ON (top-right corner).

3. **Load the extension**  
   - Click **Load unpacked**  
   - Select the **Mondrian Browsing** folder (the one that contains `manifest.json`)  
   - Click **Select** / **Open**

4. **Pin the extension (recommended)**  
   - Click the **puzzle piece** icon in Chrome’s toolbar  
   - Find **Mondrian Browsing**  
   - Click the **pin** icon so it stays visible

### How to play

1. Open any normal website (for example Wikipedia, a news site, or a blog).  
   **Note:** It does **not** work on `chrome://` pages or the Chrome Web Store.

2. Click the **Mondrian Browsing** icon in your toolbar to start the game.

3. Click **Start painting!** when the popup appears.

4. **Click blocks** on the page to paint them before the **60-second** timer runs out.

5. The first time you finish a game, enter your **name** for the **global leaderboard**.

6. Click the extension icon again to **turn the game off**.

### Tips

- Try pages with lots of boxes and sections — they make bigger, more fun paintings.
- You can **drag the score panel** by its red header bar.
- After a game ends, you can **download your painting** as a PNG.

### Troubleshooting

| Problem | What to try |
|--------|-------------|
| Nothing happens when I click the icon | Refresh the page, then click the icon again. |
| “Load unpacked” is greyed out | Turn on **Developer mode** first. |
| Leaderboard says “unavailable” | Check your internet connection and reload the extension. |
| I changed the folder | Go to `chrome://extensions` and click **Reload** on Mondrian Browsing. |
