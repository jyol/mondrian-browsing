# Mondrian Browsing

**Download & play → [jyol.github.io/mondrian-browsing](https://jyol.github.io/mondrian-browsing/)**

Turn any webpage into a Mondrian painting.

Mondrian Browsing is a Chrome extension game: open any page, then in **60 seconds** click blocks to paint them in Mondrian-style red, blue, yellow, white, and black. When you’re done, download a PNG and climb the **global leaderboard**.

---

## Getting started

**Fastest path:** open the [download page](https://jyol.github.io/mondrian-browsing/), click download, and follow the install steps.

**Or install from GitHub:**

1. Download and unzip this repo (or [`mondrian-browsing.zip`](mondrian-browsing.zip))
2. Open Chrome and go to `chrome://extensions`
3. Turn on **Developer mode** → **Load unpacked** → select the `mondrian-browsing` folder
4. Open any normal webpage (Wikipedia, news, blogs work well), then click the **Mondrian Browsing** toolbar icon
5. Paint as many blocks as you can in 60 seconds

---

## Tips

- Busier pages (nav bars, cards, lists) make nicer paintings
- Enter a nickname after your first finished run to join the leaderboard
- Click the extension icon again to quit
